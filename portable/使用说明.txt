FindLite · 寻文件 1.0.1
轻量本地文件搜索

运行环境
Windows 10 / 11，64 位，.NET Framework 4.8 或更高版本。
无需管理员权限。免安装版解压后双击 FindLite.exe。

开始使用
1. 从左侧添加需要索引的文件夹。首次扫描完成后即可搜索。
2. 输入关键词，结果自动更新；也可点击「确认搜索」或按 Enter。
3. 从左侧选择文件类型。勾选「模糊搜索」可匹配部分字符和少量错字。
4. 双击结果打开，右键可定位文件或复制路径。
5. 选中文件后点击「删除选中」或按 Delete，经确认后移至回收站。
   按 Ctrl / Shift 可以多选。此版本不删除文件夹或链接。

快捷键
Ctrl+F：聚焦搜索；Esc：清空搜索；F5：刷新索引。
搜索框 Enter：执行搜索。列表 Enter：打开；Ctrl+Enter：定位。
列表 Ctrl+C：复制选中文件的完整路径；Delete：回收站删除。

搜索语法
报告 2026       同时包含多个词
*.pdf|*.docx     或者
报告 !草稿      排除
"产品 方案"    带空格的短语
ext:pdf;docx     扩展名
path:Downloads  路径包含
type:file       文件
type:folder     文件夹

使用边界
首次索引采用文件夹遍历，尚未实现 NTFS MFT / USN 索引。
全盘初次扫描可能较慢，建议先添加常用目录。
无权限目录、目录联接和符号链接会跳过。离线目录重新可用后可按 F5。
长路径受 Windows 与 .NET Framework 当前设置约束。
内容搜索、拼音搜索和 Everything 的完整高级语法不在本版本范围内。
模糊查询会扩大结果范围；直接匹配优先，可关闭模糊搜索缩小范围。

删除操作
只处理明确选中的文件，操作前会列出待处理项目并询问确认。
采用 Windows 回收站接口，无永久删除的备用路径。
权限不足、被占用或位置不支持回收站时会显示失败原因。
恢复文件请使用 Windows 回收站。

安装和卸载
安装版默认位于 %LOCALAPPDATA%\Programs\FindLite。
可在 Windows 设置 > 应用中卸载，或从开始菜单进入卸载程序。
卸载保留索引和设置。完全清除时，关闭软件后删除 %LOCALAPPDATA%\FindLite。
软件未自动启动、未安装后台服务，未设置文件关联。
